# TodoLCI

A todo command line interface in go, nothing more.

## Usage
help
````bash
gotodo -h
````

show tasks
````bash
gotodo -show
````

add task
````bash
gotodo -add "task description"
````

mark a task as done
````bash
gotodo -done task-id
````

remove a task
````bash
gotodo -remove task-id
````

clear all task
````bash
gotodo -clear
````
